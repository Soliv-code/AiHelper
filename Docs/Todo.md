## 📝 Заметки
- OS: Windows, PowerShell
- IDE: Visual Studio 2026
- Ollama: нативно (без Docker)
- PostgreSQL: через Docker Compose (папка `Docker/`)
- Архитектура: один проект, строгая папочная структура (Services, UI, Models, Data, Components, Docker)
- Подход к БД: Database-First (SQL-скрипты, без Code-First миграций)
- Навигация: компонентная архитектура с DI-контейнером, кнопки "Назад" без потери состояния
- Состояние: хранится в БД (`user_preferences`, `app_state`), автоматическое восстановление при запуске
- UX: визуальное разделение действий и чатов в меню, inline-команды для быстрого управления
